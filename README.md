# AI Chatbot

## Description
AI Chatbot is a Java console application that simulates a simple conversation with users using predefined responses. It demonstrates the use of conditional statements, loops, string handling, and user input to create an interactive chatbot experience.

## Features
- Interactive console-based conversation
- Responds to greetings and common questions
- Displays the current date and time
- Performs basic arithmetic calculations
- Shares motivational quotes
- Tells programming jokes
- Exit option to end the conversation

## Technologies Used
- Java
- BlueJ IDE
- Scanner Class
- Conditional Statements
- Loops
- String Handling

## How to Run
1. Open the project in BlueJ.
2. Compile the `AIChatbot` class.
3. Run the `main()` method.
4. Type your questions or commands.
5. Type `exit` to close the chatbot.
